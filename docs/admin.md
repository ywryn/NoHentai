# 服务器 Admin

入口为 `/#/admin`。管理操作直接访问本机 Python / SQLite，无 GitHub 或 Vercel 管理凭证。

| 功能 | 存储与生效 |
| --- | --- |
| 收藏元数据 | `galleries` 表；抓取完整成功后事务替换 |
| 人工覆盖 | `resources` 的 overrides；与抓取结果分离，保存立即生效 |
| 实体书单 | `books` 表按位置保存，允许重复书目编号；保存立即生效 |
| 每日规则 | `resources` 的 daily；后续任务读取 |
| 翻译模型、JSON 模式 | `resources` 的 translate；后续请求读取，无需重启 |
| 默认 OCR | 同上；重新进入翻译工作台读取 |
| 内容历史 | `history`；保存快照、版本、时间与操作说明 |
| 同步队列与结果 | `jobs`；排队、运行状态与结果摘要可在后台查看 |
| 服务凭证 | `credentials` 中 Fernet 加密；未覆盖的值回退服务器环境变量 |

首页通过 `/api/galleries` 在 SQLite 中执行搜索、分类计数与分页，每次返回当前页（默认 30 条，最多 100 条）及对应标签文案；详情使用 `/api/galleries/{gid}`，标签联想使用 `/api/tags/suggestions`。首页与详情不下载完整收藏或翻译库。

其他兼容页面仍可使用 `/data/galleries.json`、`daily_search.json`、`future_digi.csv`、`stats.json`、`translations.json` 等路径。这些都是 API 响应，来自数据库。统计按当前数据计算。隐藏同时作用于收藏、每日列表和统计，书单独立保留。隐藏控制展示，不构成私有访问权限。

## 登录与权限

`ADMIN_PASSWORD` 至少 16 字符，和 `TRANS_PASSWORD` 分离。只有 verify 操作接受原始管理密码，其余管理操作必须使用随机会话凭证。数据库仅保存会话 Token 的 SHA-256；Token 前缀仍为 `admin.v1.`，保留原有浏览器登录体验。

记住登录的会话有效期为 30 天，不勾选时为 12 小时；分别保存于 localStorage / sessionStorage。退出会撤销服务器当前会话；管理密码更改并重启 API 后，所有旧会话失效。旧 Vercel 签名会话不能用于新后端，需要重新登录。会话 Token 具备管理权限，应与密码同等保护。所有生产访问使用 HTTPS。

登录每个来源 IP 五分钟最多 10 次，限流计数存 SQLite，API 重启不会清零。翻译验证、图片及付费调用另有限流。Nginx 只将实际客户端地址传入，Uvicorn 仅信任本机代理。不要直接开放 8000 端口。POST 拒绝不在 `ALLOWED_ORIGINS` 中的浏览器来源；请求不使用 Cookie 鉴权。

## 编辑与冲突

加载返回数据库版本号（兼容前端字段 `sha`）；保存通过 `BEGIN IMMEDIATE` 在同一事务中检查版本、验证引用、写入内容与历史。旧版本返回 409，草稿留在浏览器，可导出后重新加载合并。无需提交 Git、构建或部署。

画廊只允许覆盖 title、title_jpn、tags、category、uploader、hidden。移除覆盖恢复来源值，空数组清空标签。收藏取消后的旧覆盖仍保留，来源恢复后重新应用。

新增书单关联必须存在于收藏；已有站外关联允许保留并提示。书目编号允许重复，封面只能填已有文件名，不能提交任意路径。历史页提供记录查看，完整恢复使用数据库备份；暂未提供在线历史回滚按钮。

## 凭证管理

只允许 `.env.example` 中的业务凭证白名单。后台不返回旧明文，也不允许修改 ADMIN_PASSWORD、加密主密钥或服务器路径。后台替换的值优先于环境文件，后续请求 / 新任务读取即生效。替换只说明保存成功，不能证明第三方凭证有效。

数据库内容使用 `CREDENTIAL_ENCRYPTION_KEY` 加密。主密钥只在服务器环境文件中；必须单独备份，丢失后不能解密。备份数据库也包含加密凭证。需要回到环境变量值时，在停机备份后通过本机 SQLite 删除对应 credentials 行；后台不提供显示或删除凭证入口。主密钥不要直接改值；需要轮换时先解密并重新加密全部 credentials。

审计记录只保存凭证名称和操作时间，不保存旧值或新值。API 不转发第三方原始错误，避免响应中泄露服务密钥。上游图片只允许 HTTPS、公开地址及指定来源域名，重定向逐跳校验；Cookie 只发送给精确匹配的 exhentai.org，不传给 H@H 节点。

## 同步任务

可以触发全量、收藏、标签翻译或每日搜索。只接受固定任务类型，无任意命令执行或 URL 任务。相同类型已排队或运行时返回已有任务，不重复加入。worker 单实例串行处理任务，每个任务在独立子进程执行，上限六小时。

任务在 SQLite 持久保存。服务正常运行时每十秒写心跳；admin 测活检查数据库和心跳。worker 重启后将中断的运行标为失败，排队任务继续处理。可手动重跑已完成任务。结果页展示阶段与结果摘要，不公开抓取原始响应或可能含敏感信息的日志。

全量任务所有步骤完成才一起提交。抓取期间改变 daily 规则时，任务拒绝发布旧规则结果，需重新运行。翻译 / OCR 与同步共用业务凭证，但管理权限完全分开。
