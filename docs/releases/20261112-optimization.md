# 前后端优化正式发布 · 2026-11-12

本次由用户明确授权合并、推送及重新部署主分支。业务代码基线为 `634e9cd`，来自前后端综合验收分支；原生产提交为 `757a5da`。地图试验分支已取消，其提交 `a606dff`、地图页面、API、地图数据及新增地图依赖不进入本次发布。

## 发布内容

- 前台统一响应式列表、搜索筛选与分页；保留首页/尾页跳转、原有单行标签展示并适配主题；手机列表显示收藏夹，封面为 62×88px 并垂直居中。
- 阅读器改进书页/连续阅读、页目录、键盘与长列表渲染；翻译工作台改进操作和状态反馈；统计页保留分类饼图与 Female/Male 柱图，新增近期活动指标；Admin 改进导航、表单及移动端可用性。
- 后端按 ID/批量读取减少重复查询，复用一致性词典缓存，原子化限流及索引化过期维护；限制上游 JSON 响应大小，增加请求 ID 和脱敏异常日志。API 契约不变，依赖和 systemd 单元不变。

## 发布前验证

- 99 项 Python 集成/接口测试、18 项 JavaScript 契约测试通过。
- 完整生产构建及 Vue/TypeScript 检查通过；共享搜索/分页浏览器测试及一次性数据库的全站浏览器冒烟测试通过。
- 生产 SQLite 一致性副本经新代码初始化后完整性检查为 `ok`，schema 保持 3；画廊、书目、覆盖、规则、凭据、账户与调度表的内容哈希不变。
- 发布不导入验收数据库，不执行 OCR、翻译或同步测试任务，不更改生产密钥、数据库路径或调度配置。

## 部署与回滚

主分支为 `master`，正式代码位于 `/opt/nohentai`，正式入口为 `https://nohentai.com/`。先备份生产数据库、配置和原静态版本路径，等待 worker 空闲后停止 worker/API，快进更新生产 checkout，启动 API 验证，再原子发布静态前端并恢复 worker。具体发布提交及前后静态目录记录于本次 `/var/backups/nohentai/*-optimized-master/release.json`。

若上线检查失败，恢复生产代码 `757a5da` 和原前端 release，再启动 API/worker。新增索引与旧代码兼容，不应为代码回滚覆盖已有业务数据；一致性数据库备份仅在确有数据损坏时按维护流程恢复。配置和数据副本保留在受限权限的备份目录。

此前的验收记录见 [综合验收](../reviews/integrated-20261112.md)、[后端性能审查](../reviews/backend-20261111.md)。这些记录中的“待生产合并”描述属于历史阶段，本次发布授权以本记录为准。

## 同日分页间距与滚动条修正

首页、书单、每日结果区共用一套布局：筛选区到上方分页器间距 20px，分页器与列表上下间距均为 8px；分页按钮和触控尺寸保持原规格。每日移除独立结果标题行，筛选数量复用顶部计数，重置操作放入搜索栏，手机筛选时搜索框保持整行宽度。

前台隐藏滚动条外观，保留原生滚轮、触控和键盘滚动；热力图滚动容器可获得键盘焦点并横向滚动。此规则不改变 Admin 的滚动条策略。

完整前端构建、类型检查、共享搜索分页浏览器回归通过；真实验收数据下复核桌面和手机间距、筛选重置、滚轮、PageDown、热力图 ArrowRight 和深色主题，未捕获 JavaScript 错误。此次只发布静态前端，无数据库或后端服务变更。
