# UI / UX 优化验收

> 历史记录：8443 单独验收站已于 2026-11-12 关闭；当前综合验收地址见 [前后端综合验收](integrated-20261112.md)。

基线：线上 `/opt/nohentai` 与开发仓库均为 `757a5da95c66406493cddd8cc4648252768d11d0`。
分支：`feat/ui-experience-20261111`。

## 改进

- 首页取消嵌套卡片及重阴影；统一页面宽度、标题、留白和深浅主题。桌面导航与手机导航使用相同中文名称。
- 手机搜索输入独占一行，分类和语法按需展开；修复分类弹层关闭后 `aria-expanded` 不同步，以及触屏选择搜索建议。
- 列表调整字号、封面比例及行间距，手机允许两行标题；封面失败显示文字占位。
- 分页方向键扩大到 44px，删除与端点页码重复的首末按钮。跳页使用 Enter 提交，失焦取消，越界值回到有效页码。首页翻页支持浏览器返回。
- 同页搜索不强制滚动到顶部；换页仍回到顶部。增加跳至内容的键盘入口。
- 每日规则默认折叠；精简统计、翻译入口与详情页重复说明；修复每日规则样式混在外部 style 标签内的问题。
- 后台登录改为单一表单，移除宣传文案和重复身份区；后台导航、表单、按钮与前台统一视觉语言，手机输入字号避免自动缩放。
- 请求失败与空结果分开显示，提供重试；保留骨架、减少动态效果偏好、键盘焦点和隐私模式。

## 验收环境

- 前台：`https://nohentai.com:8443/`
- 后台：`https://nohentai.com:8443/#/admin`
- 前端静态构建：`/srv/nohentai/ui-preview/www`
- API：`nohentai-ui-preview.service`，仅监听 `127.0.0.1:8001`。
- 数据：SQLite backup API 生成的线上一致性副本，位于 `/var/lib/nohentai-ui-preview`；原管理员密码可登录。
- 预览 Cookie 为 `nohentai_ui_preview`，与正式站隔离。新增 `ADMIN_COOKIE_NAME` 环境变量，生产默认值保持原样。
- 不启动预览同步 worker：可验收后台布局及内容保存，但提交的同步任务不会执行。未连接额外第三方服务进行测试。
- Nginx 独立配置：`/etc/nginx/conf.d/nohentai-ui-preview.conf`；开放 TCP 8443，原线上端口不变。

新增布局测试覆盖 360 / 600 / 768 / 1024 / 1440px、深浅主题、搜索宽度、44px 分页、弹层 ARIA、分页历史、跳页、加载 / 空结果 / 失败 / 重试及后台宽度。测试使用虚拟条目与本地临时数据库，不修改线上数据。截图中的封面使用占位图，检验布局而不依赖远端图片加载。
