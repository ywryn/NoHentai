## 依据与取舍

- **阅读**：翻页阅读与连续滚动需要不同的输入行为。书页模式保留左右点按、滑动和键盘方向键；连续滚动由浏览器原生手势控制，工具栏可轻触画面收起，收起后页码按钮始终可恢复。工具栏不再重复显示返回与关闭，阅读设置统一收进面板，页码可直接打开目录。
- **翻译**：每页最常见的任务是识别、查看和修正。识别后主操作随结果切换为补译或重新识别，译文与原图可在顶栏直接切换。桌面点图中气泡会定位右侧原文；手机气泡卡可以直接打开该条的编辑器。低置信度条目只在需要核对时标记，避免每条都显示百分比。
- **详情**：内容分类与标签有各自用途，但标签区无需再次写“分类标签 / Tags”，也无需解释点击和复制按钮。保留可访问名称与必要反馈。
- **统计**：从现有每日收藏计数衍生近 30 天新增及活跃天数，与总量并列；季度图不再重复写累计总量。这两项反映最近使用情况，和总量、季度趋势互补。没有额外 API 或数据库变更。

## 验证

检查桌面、平板、手机宽度及不同高度，覆盖首次加载、图片失败、翻页、缩放、气泡选择、翻译处理、空结果和错误重试。运行前端构建、单元测试、阅读与翻译浏览器回归，之后更新独立验收端口 `https://nohentai.com:8443/`。该端口仍使用独立数据库快照。

## 后续体验审查与改进

- **超长画廊**：页目录每次展示 120 页，支持直接输入页码；侧栏只保留当前页附近 80 页。超过 200 页时，连续滚动按 120 页分段，段尾可进入下一段，段首可返回上一段。这样可以避免一次挂载数千个图片组件和观察器；普通长度画廊保持连续滚动。目录关闭后焦点回到页码按钮，弹窗开启时键盘方向键不会误翻背后的页面。
- **统计判读**：首次请求期间保留稳定的加载区域；请求失败时只显示可重试错误，不出现空图。分类按数量排序并直接标数，Female/Male 排行改为可搜索的标签列表，先展示前十项并可展开全部。手机上的四组命名空间排行改为切换查看，桌面仍并列比较。所有数据沿用 `/api/stats`，没有改变 API 或统计口径。
- **验证**：新增 400 页目录、分段滚动、页码跳转和统计失败场景的浏览器回归；完整浏览器流程覆盖统计真实数据、Admin 操作和移动导航。验收服务继续使用独立数据库快照和 8443 端口。
