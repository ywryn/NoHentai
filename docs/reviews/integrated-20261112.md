## 优化内容

### 前端产品体验

- 首页与列表统一桌面、平板和手机的信息层级；搜索、分类、建议、分页与浏览器历史协同，加载、空结果和失败重试状态清晰。
- 详情页删除重复标签说明；阅读器优化书页与连续滚动、工具栏恢复、页目录、键盘操作和长画廊的分段渲染；翻译工作台优化识别、翻译、气泡编辑和手机操作路径。
- 统计页增加最近 30 天新增与活跃天数，保留原有分类饼图和 Female/Male 柱图；其他标签排行可搜索，手机端可切换类别。Admin 优化登录、导航、表单与移动端基本可用性。
- 根据验收反馈，列表视图标签保留原有单行渐隐样式并适配当前主题配色；分页器缩小桌面按钮和上下留白，恢复首末页快捷跳转，手机端保留 44px 触控区域。
- 手机端列表封面与右侧信息区域垂直居中对齐，避免标题换行时封面贴在行顶部。
- 手机端列表保留所属收藏夹信息，封面尺寸与桌面列表统一为 62×88px。

### 后端性能与可靠性

- 画廊详情按 ID 读取覆盖，翻译词典按目录修订号在事务一致的前提下复用；后台列表和任务步骤批量读取，消除逐条查询。
- 限流计数改为原子 UPSERT，索引化过期维护；上游 JSON 响应流式限额；API 增加 `X-Request-ID`，失败日志不输出敏感异常原文。
- 现有 API 请求与数据响应结构不变；数据库仅增加兼容性索引，不改变表、字段或 `user_version`。性能复测和具体取舍见 [后端审查](backend-20261111.md)。

## 隔离与限制

- 静态前端和后端代码均来自综合分支。API 在 `127.0.0.1:8003` 运行，经 Nginx 8445 提供 HTTPS。数据为生产 SQLite backup API 创建的一致性副本，位于 `/var/lib/nohentai-integrated-review`；会话、凭据、缓存与租约已清空，使用独立 Cookie 与密钥。
- 综合验收服务不运行 worker 或定时任务，设置 `NOHENTAI_DISABLE_UPSTREAM=1` 和 systemd 外网限制。涉及外部图像、OCR、翻译和服务连通性的操作会返回受控 503。这些操作的交互与异常路径由模拟上游的浏览器测试验证；验收站不会调用生产第三方配额。
- Admin 可使用数据库副本创建时的管理员密码登录；在此站的保存、上传和任务排队只影响副本。排队任务不会被执行。生产 API、worker、数据库及 443 网站保持原样。
