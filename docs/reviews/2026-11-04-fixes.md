## 已完成的安全清理

- 删除无引用的 `SettingsPanel.vue`、`PageNav.vue`、`AdminPanePlaceholder.vue`。
- 移除无调用者的全量收藏 / 词典加载器和无效缓存失效调用。
- 移除旧浏览器 Token 读写函数；保留 `clearAdminLogin()` 迁移清理。
- 移除已下线服务操作下拉框的前端计算函数和对应旧测试。
- 旧后台配置路径重定向到统一服务页。
- Python 统计参考实现移入 `tests/statistics_reference.py`，仍作为 SQL 聚合独立对照。
- 更新旧浏览器断言：模型改回最初显示值才属于放弃修改，不再假设原值为空。调整 locator 断言超时，减少资源紧张时的误报。

## 有意保留

- 隐藏的 TagExplorer 功能暂不删除或恢复入口，保留产品选择；标签补全仍在使用。
- 初次导入快照、抓取共享函数、必要的 `/data` 兼容读取、旧路径跳转以及停用的旧 timer 保留。未对种子快照或历史设计文档做大规模搬迁。
- 旧抓取 CLI 与部分仅作参考的 JS 校验尚未整体拆分，避免将仍承担导入或测试作用的代码当作纯死代码删除。
- 既有手工译文和 OCR 本地缓存不自动清空。修复前已串页的缓存无法可靠识别归属，受影响页面需重新执行 OCR / 翻译。
- 共享 hash 资源不自动清理，换取旧标签页可用性；后续可单独制定引用检查和保留期。
