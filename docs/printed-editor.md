# 实体书单编辑

入口 `/#/admin/printed`，使用独立管理密码登录。旧 `/#/printed/edit` 保留跳转，旧 `/api/printed-books` 返回 410；翻译密码不能编辑书单。

书单从 SQLite 加载，保存后直接生效。书目信息与画廊关联独立，选候选只改变 sid。允许重复书目编号，保留已有站外关联，新关联必须存在于收藏。cover 填已有本地封面文件名，不支持文件上传。

保存使用数据库版本检查防止覆盖他人的编辑。发生 409 时，先导出 CSV / 保留草稿，再加载并合并最新版本。内容与历史在同一事务保存；每日同步不会覆盖书单。数据库备份和恢复见 [部署文档](vultr-deployment.md)。
