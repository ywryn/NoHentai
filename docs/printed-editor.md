# 实体书单编辑

入口 `/#/admin/printed`，使用管理账户；旧 `/#/printed/edit` 跳转到此处。翻译密码不能管理书单。

列表可搜索并逐条编辑，书目使用稳定内部 UUID，用户填写的书目编号允许重复。每条版本独立，旧版本冲突保留草稿，可导出后合并。新增画廊关联需存在于收藏，旧站外关联可保留；提供标题、gid、链接和标签搜索关联候选。

封面支持 PNG / JPEG / WebP 上传，最大 8MB，服务器验证图片、缩放至最长 1600 像素并生成 WebP。上传后保存书目才应用；原有静态封面继续兼容。删除书目不立即删除封面文件，避免历史恢复丢图。

保存、删除和排序直接生效，每日同步不改书单。“修改历史”查看差异、恢复内容；删除项从“修改记录”恢复，保留内部 ID 并追加末尾。备份需同时保留数据库和配套 media.zip，见 [部署文档](vultr-deployment.md)。
