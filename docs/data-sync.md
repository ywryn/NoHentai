# 收藏同步完整性

首页总数来自 `galleries.json`，统计页数据由 `generate-stats.js` 在构建前生成。

同步只有在收藏分页和元数据请求完整完成后才覆盖数据。分页 HTTP 错误、没有可解析条目的页面、分页循环、重复画廊和缺失的元数据批次都会使同步失败并保留现有文件。分页日志记录每页及累计数量，方便检查抓取在哪里中断。

如果结果比当前快照减少超过 20%，即使请求返回 HTTP 200，也会拒绝保存。请检查收藏页筛选、认证和访问限制。只有确认是主动批量删除收藏时，才在运行同步脚本的环境中临时设置 `ALLOW_FAVORITES_SHRINK=1`；不要为消除报错而长期启用。

2026-10-23 修复了一次部分结果覆盖：当时最新文件精确等于前一天完整快照的前 2,000 条，缺失 2,214 条。恢复时保留最新的前 2,000 条，其余由 `ex_backup_20261022-231421.json` 补回；这些补回条目是历史数据，不表示重新抓取成功。后续完整同步成功后会正常刷新。
